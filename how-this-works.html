📋 Resumen Ejecutivo (No-Técnico)

Neuro Drive es una simulación de inteligencia artificial evolutiva donde 8 vehículos autónomos aprenden a conducir mediante un proceso inspirado en la selección natural de Darwin.

Cada vehículo posee un "cerebro" digital (red neuronal) que procesa información sensorial y toma decisiones de conducción. Los vehículos compiten entre sí, y el más exitoso transmite su configuración cerebral a la siguiente generación, con pequeñas variaciones aleatorias (mutaciones).

Con el tiempo, este proceso de selección + herencia + mutación produce vehículos cada vez más competentes, capaces de navegar obstáculos que inicialmente resultaban imposibles.

Tecnología Core Redes Neuronales Artificiales + Algoritmos Genéticos
Método de Aprendizaje Neuroevolución (evolución de pesos sinápticos)
Tiempo de Convergencia 10-50 generaciones para comportamiento básico
Aplicación Real Base de sistemas de conducción autónoma

Ciclo de Vida de una Generación

  1. Inicialización: N coches nacen con copias mutadas del mejor cerebro anterior
  2. Simulación: Cada frame actualiza sensores → red neuronal → física
  3. Evaluación: Se calcula fitness continuo (distancia recorrida)
  4. Terminación: Cuando todos los coches colisionan
  5. Selección: El coche con mayor fitness es seleccionado
  6. Reproducción: Su cerebro se clona y muta para la siguiente generación

🧠 Red Neuronal

Tipo de Red

Feedforward Neural Network (Perceptrón Multicapa) sin backpropagation. Los pesos se optimizan mediante algoritmo genético, no mediante descenso de gradiente.

Implementación del Feedforward

static feedForward(givenInputs: number[], network: Network): number[] {
  // Asignar inputs a la primera capa
  let outputs = Level.feedForward(givenInputs, network.levels[0]);

  // Propagar a través de capas ocultas
  for (let i = 1; i < network.levels.length; i++) {
    outputs = Level.feedForward(outputs, network.levels[i]);
  }

  return outputs;
}

Función de Activación: tanh

Se utiliza tangente hiperbólica (tanh) como función de activación por sus propiedades:

tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))
  • Rango: (-1, 1) - ideal para outputs de dirección
  • Centrada en cero: Facilita el aprendizaje
  • Gradientes más fuertes: Comparado con sigmoid
  • Suave y continua: Permite control proporcional
// En Level.feedForward()
for (let i = 0; i < level.outputs.length; i++) {
  let sum = level.biases[i];
  for (let j = 0; j < level.inputs.length; j++) {
    sum += level.inputs[j] * level.weights[j][i];
  }
  // Activación tanh para outputs continuos
  level.outputs[i] = Math.tanh(sum);
}

🧬 Algoritmo Genético

Concepto

El sistema implementa un algoritmo genético (GA) simplificado para optimizar los pesos de la red neuronal. A diferencia de backpropagation, no requiere función de pérdida diferenciable ni cálculo de gradientes.

Componentes del GA

1. Representación del Genoma

El "genoma" de cada individuo es el conjunto completo de pesos y biases de su red neuronal, almacenado como un objeto JSON serializable: 

interface Network {
  levels: Level[];  // Array de capas
}

interface Level {
  inputs: number[];
  outputs: number[];
  biases: number[];     // Sesgos por neurona
  weights: number[][]; // Matriz de pesos
}

2. Selección (Elitismo Puro)

Se utiliza selección elitista: solo el mejor individuo (mayor fitness) se reproduce. Esto garantiza convergencia pero puede llevar a óptimos locales. 

// Selección del mejor (main.ts)
const sortedCars = [...cars].sort((a, b) => b.fitness - a.fitness);
bestCar = sortedCars[0];

3. Mutación

Cada peso tiene probabilidad mutationRate de ser modificado mediante interpolación lineal hacia un valor aleatorio:

w' = lerp(w, random(-1, 1), mutationRate) 
static mutate(network: Network, amount: number = 0.1) {
  network.levels.forEach(level => {
    // Mutar biases
    for (let i = 0; i < level.biases.length; i++) {
      level.biases[i] = lerp(
        level.biases[i],
        Math.random() * 2 - 1,  // Valor aleatorio [-1, 1]
        amount
      );
    }
    // Mutar pesos (mismo proceso)
    for (let i = 0; i < level.weights.length; i++) {
      for (let j = 0; j < level.weights[i].length; j++) {
        level.weights[i][j] = lerp(
          level.weights[i][j],
          Math.random() * 2 - 1,
          amount
        );
      }
    }
  });
}

4. Variación de Tasa de Mutación

Para balancear exploración vs explotación, se aplican diferentes tasas: 

// 30% de la población: mutación conservadora (explotar)
if (i < N * 0.3) {
  variableMutation = mutationRate * 0.5;
}
// 70% restante: mutación agresiva (explorar)
else {
  variableMutation = mutationRate * (1 + Math.random());
}

Trade-off Exploración/Explotación: Mutación alta explora más soluciones pero puede perder buenas configuraciones. Mutación baja refina soluciones existentes pero puede estancarse en óptimos locales.

👁️ Sistema de Sensores

Técnica: Ray Casting

Cada vehículo proyecta 7 rayos desde su posición frontal. Los rayos detectan intersecciones con obstáculos (bordes de carretera y otros vehículos).

Ray 0 (↑) │ Ray 1 │ Ray 6 ╲ │ ╱ Ray 2 ╲ │ ╱ Ray 5 ╲ ╲ │ ╱ ╱ ╲ ╲ │ ╱ ╱ ╲ ╲ │ ╱ ╱ ╲ ╲│╱ ╱ Ray 3 ──────[CAR]────── Ray 4 Spread angle: π/2 (90°) Ray count: 7 Ray length: 150 units

Cálculo de Intersección

Se utiliza el algoritmo de intersección de segmentos de línea basado en ecuaciones paramétricas: 

#getIntersection(A, B, C, D) {
  // Línea 1: P = A + t(B-A), t ∈ [0,1]
  // Línea 2: P = C + u(D-C), u ∈ [0,1]

  const tTop = (D.x - C.x) * (A.y - C.y) - (D.y - C.y) * (A.x - C.x);
  const uTop = (C.y - A.y) * (A.x - B.x) - (C.x - A.x) * (A.y - B.y);
  const bottom = (D.y - C.y) * (B.x - A.x) - (D.x - C.x) * (B.y - A.y);

  if (bottom != 0) {
    const t = tTop / bottom;
    const u = uTop / bottom;

    // Intersección válida si ambos parámetros están en [0,1]
    if (t >= 0 && t <= 1 && u >= 0 && u <= 1) {
      return {
        x: A.x + (B.x - A.x) * t,
        y: A.y + (B.y - A.y) * t,
        offset: t  // Distancia normalizada [0,1]
      };
    }
  }
  return null;
}

⚙️ Física del Movimiento

Modelo de Vehículo

Se utiliza un modelo simplificado de cinemática 2D con las siguientes propiedades:

Propiedad Valor Descripción
acceleration 0.2 Incremento de velocidad por frame al acelerar
maxSpeed 3.5 - 5.5 Velocidad máxima (modulada por NN)
friction 0.05 Decremento de velocidad por frame
turnRate 0.04 rad Velocidad angular máxima por frame

Ecuaciones de Movimiento

#move() {
  // Aceleración
  if (this.controls.forward) this.speed += this.acceleration;
  if (this.controls.reverse) this.speed -= this.acceleration;

  // Límites de velocidad
  if (this.speed > this.maxSpeed) this.speed = this.maxSpeed;
  if (this.speed < -this.maxSpeed / 2) this.speed = -this.maxSpeed / 2;

  // Fricción (drag)
  if (this.speed > 0) this.speed -= this.friction;
  if (this.speed < 0) this.speed += this.friction;
  if (Math.abs(this.speed) < this.friction) this.speed = 0;

  // Giro (solo si hay velocidad)
  if (this.speed != 0) {
    const flip = this.speed > 0 ? 1 : -1;
    this.angle -= this.steeringIntensity * 0.04 * flip;
  }

  // Actualización de posición
  this.x -= Math.sin(this.angle) * this.speed;
  this.y -= Math.cos(this.angle) * this.speed;
}

Detección de Colisiones

Se utiliza Separating Axis Theorem (SAT) simplificado mediante verificación de intersección de polígonos: 

#polysIntersect(poly1, poly2) {
  for (let i = 0; i < poly1.length; i++) {
    for (let j = 0; j < poly2.length - 1; j++) {
      const touch = this.#getIntersection(
        poly1[i], poly1[(i + 1) % poly1.length],
        poly2[j], poly2[j + 1]
      );
      if (touch) return true;
    }
  }
  return false;
}

📊 Función de Fitness

Definición

La función de fitness determina qué tan "bueno" es un individuo. En Neuro Drive, se utiliza una métrica simple pero efectiva:

fitness = 100 - Y

Donde Y es la coordenada vertical del vehículo. Como Y disminuye al avanzar (sistema de coordenadas Canvas), mayor distancia recorrida = mayor fitness.

Justificación del Diseño

  • Simplicidad: Una métrica simple evita que la IA encuentre "exploits"
  • Monotonicidad: Siempre recompensa avanzar más lejos
  • Sin penalizaciones artificiales: Solo la colisión termina la carrera

Diseño anterior (descartado): Se probó un sistema que requería adelantar coches y penalizaba estancamiento. La IA encontró "exploits" como ir lento junto al tráfico. La solución fue simplificar a solo distancia.

🚗 Sistema de Tráfico

Generación Procedural

El tráfico se genera de forma procedural con dificultad progresiva: 

createTraffic() {
  for (let row = 0; row < 40; row++) {
    const y = -300 - (row * 120); // 120 unidades entre filas

    let openLane;
    if (row < 3) {
      // Primeras 3 filas: carril central SIEMPRE abierto
      openLane = 1;
    } else if (row < 8) {
      // Filas 3-7: centro O adyacente (transición)
      openLane = Math.random() < 0.5 ? 1 : (Math.random() < 0.5 ? 0 : 2);
    } else {
      // Resto: completamente aleatorio (desafío real)
      openLane = Math.floor(Math.random() * 3);
    }

    // Bloquear 2 de 3 carriles con obstáculos
    for (let lane = 0; lane < 3; lane++) {
      if (lane !== openLane) {
        traffic.push(new Car(getLaneCenter(lane), y, 30, 50, "DUMMY", 2));
      }
    }
  }
}
